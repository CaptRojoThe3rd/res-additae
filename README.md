
# Res Additae for Minecraft 1.7.10

## Features

* New tools, such as scythes and halberds.
* New things to make tools with, such as silver and platinum.
* Tons of new blocks, including new stone types, wood types, and more colored blocks.
* New forest biomes.
* A new dimension called The Depths, which has many interesting generation features.
* A mana bar and charms that use mana.
* And more!

## Supported versions

Currently, this mod only supports 1.7.10, as that is the version I plan to play it on (with NTM: Space and other mods).
