
# Res Additae for Minecraft 1.7.10

## Features

* New tools, such as scythes and halberds.
* New things to make tools with, such as silver and platinum.
* Tons of new blocks, including new stone types, wood types, and more colored blocks.
* New forest biomes.
* A new dimension called The Depths, which has many interesting generation features.
* A mana bar and charms that use mana.
* And more!

## Updates, versioning, and changelog

Stable/release versions of the mod use MAJOR.MINOR.PATCH (e.g. 1.2.3) versioning.
Alpha/beta/snapshot versions of the mod use build numbers (e.g. X0009 or Build #0009). Note that
stable/release versions still have build numbers and a new stable/release version will increment
the build number.

Not all builds will be uploaded to Modrinth, due to any of the following reasons:
* The new build is unstable
* The new build is a demo/feedback is wanted
* It has been too soon since a previous release/the build doesn't add much

A changelog for every version of the mod can be found [here](../main/src/main/resources/changelog.txt).

## Supported versions

Currently, this mod only supports 1.7.10, as that is the version I plan to play it on (with NTM: Space and other mods).
